NetGreeting
===========

A video-call program, like Microsoft
NetMeeting on a beige PC in 1999.

There is no account.
Open it. Type your name.
Call → Directory.
If a friend is on the list, call them.

Chat, whiteboard, files, desktop share.

The people in the windows are stand-ins.

Both of you need the app open.
The directory is only a phone book;
the call goes computer to computer.
Not encrypted. Friends only.

Double-click an icon on the left
to download for your computer.

NetGreeting Source on GitHub

Version 0.1

Call a person on another computer.

NetGreeting is a small video-call program in the spirit of Microsoft NetMeeting. There is no account. You type your name, open the directory, and call whoever is on it.

Get the program

Windows netgreeting-0.1.0-win64.exe Macintosh netgreeting-0.1.0-Darwin.dmg Ubuntu & Debian netgreeting_0.1.0_amd64.deb Fedora netgreeting-0.1.0-1.x86_64.rpm

Everything else, including a Windows zip

How you use it

  1. Install it and open it.
  2. Under Tools → Options, type your first name.
  3. Open Call → Directory.
  4. Click a name, then Call. If someone calls you, click Accept.

While you are in a call you can chat, draw on a whiteboard, send a file, or share your screen (they can watch; they cannot take over).

The people in the pictures are stand-ins, not real users. Both of you need the app open at the same time. The directory is only a phone book — the call goes from your computer to theirs, and a home network may block it. Calls are not encrypted.
